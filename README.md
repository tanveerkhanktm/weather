# Weather Dashboard

A simple Weather Dashboard that fetches real-time weather data using OpenWeatherMap API.

## Features
- Real-time temperature
- Humidity data
- Wind speed
- Weather condition
- City search

## Technologies Used
HTML
CSS
JavaScript
OpenWeatherMap API

## How to Run

1. Download project
2. Add your OpenWeatherMap API key in script.js
3. Open index.html in browser
